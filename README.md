
# Quotes App 📱✨

A native Android motivational quotes application built with Java and XML layouts in Android Studio. 

The app allows users to view inspirational quotes and easily share them with friends using Android system share intents.

---

## 🚀 Features

* **Random Quote Generator:** Displays inspirational quotes at random upon launch or when tapping the "Next Quote" button.
  
* **Native Android UI:** Designed with clean linear layouts, card structures, and responsive typography using standard Android widgets (`TextView`, `Button`).
  
* **Share Integration:** Built-in Android intent action supporting quick sharing of any quote via messaging or social apps.

---

## 🛠️ Tech Stack & Concepts

* **Language:** Java


* **IDE:** Android Studio
  
* **UI Design:** XML Layouts
  


* **Core Concepts:**
  
* Array & String Collections
  


* Random Number Generation (`java.util.Random`)


* Event Listeners (`View.OnClickListener`)


* Android System Intents (`Intent.ACTION_SEND`)
